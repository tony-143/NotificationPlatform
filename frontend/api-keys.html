Authentication guide

Credential

Stored as a SHA-256 hash

How this key is protected

  • Secrets are generated with a cryptographically secure random number generator on the server.
  • Only a SHA-256 hash and a non-secret prefix are stored. The raw key cannot be recovered from the database.
  • The key is scoped to the signed-in account; it cannot read another tenant's notifications.
  • Revoking a key immediately makes authenticated API calls fail with 401.
  • Use the key from a trusted backend only — never in public browser code or mobile apps.
This portal keeps the secret in memory only while the reveal dialog is open. Nothing is written to local storage, session storage, cookies or logs.
